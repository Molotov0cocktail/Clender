# T24 — Thinking 向下展开与视口锚定

## 目标

- 展开/收起 Thinking 时保持点击标题视觉位置，隔离不同会话状态。

## 非目标

- 不改变消息持久化格式、AI 请求预算或响应协议。

## 影响文件

- `ui/ai_chat_widget.py`、聊天 UI 专项测试。

## 接口/数据影响

- 消息渲染增加滚动策略；展开键包含 conversation ID。

## 风险

- QTextDocument anchor 坐标波动；新消息不再滚底；信号重复连接。

## 实施步骤

- [ ] 先写长历史、会话隔离、畸形 URL 测试并确认旧实现失败。
- [ ] 实现锚点差值恢复和输入校验。
- [ ] 验证新消息、切换会话、主题回归。

## 测试矩阵

- 正常：历史中间 Thinking 展开/收起。
- 边界：首末、长短内容、多个会话。
- 异常：坏、负数、越界链接。
- 回归：初始/新消息滚底、主题重绘。

## 回滚方式

- 恢复全量重绘滚底逻辑，不影响持久化数据。

## 完成定义

- [x] 点击标题位置容差内稳定，内容向下增长。
- [x] 聚焦 Qt offscreen 测试通过。

## 实施结果

- 旧实现 4 项专项测试得到 3 失败、1 错误：标题偏移 1356px、展开状态跨会话串联、畸形 URL 崩溃。
- 展开状态改为 `(conversation_id, think_index)`；命名 HTML anchor 的文档坐标差用于恢复滚动位置。
- 非法、负数、越界 toggle 被忽略；初始、新消息、切换和主题重排仍滚到底部。
- `tests.test_ai_chat_widget`、UI smoke 与 AI service 共 12/12 通过。

# T27 — 今日桌面悬浮窗

## 目标

- 新增可配置今日悬浮窗、相交查询、只读详情、托盘入口和自动刷新。

## 非目标

- 不在悬浮窗编辑事件；不新增数据库字段或第三方依赖。

## 影响文件

- 新增 `floating_window_logic.py`、`ui/daily_floating_window.py`、`ui/event_detail_dialog.py`、`ui/app_settings.py`
- 修改 `constants.py`、`database.py`、`event_service.py`、`ui/main_window.py` 与相关测试。

## 接口/数据影响

- 新增相交查询；配置新增开关、透明度、时间范围、geometry；MainWindow 数据变化链刷新悬浮窗。

## 风险

- 跨日边界、几何离屏、频繁配置写入、窗口生命周期、隐私与低透明度可读性。

## 实施步骤

- [ ] 先写配置、过滤、DB 相交、信号/生命周期测试并确认旧实现缺失。
- [ ] 实现纯逻辑和服务查询。
- [ ] 实现设置、悬浮窗、详情与 MainWindow 编排。
- [ ] 验证手工/AI data_changed、主题、托盘、午夜刷新。

## 测试矩阵

- 正常：启停、透明度、时间范围、列表排序、点击详情。
- 边界：端点、跨日、空列表、30/100%、多屏几何。
- 异常：坏配置、倒序时间、保存失败、旧坏事件。
- 回归：主程序每次数据修改立即刷新、托盘仍显示、主题与 offscreen。

## 回滚方式

- 默认关闭并从 MainWindow 断开；旧版本忽略新配置，schema 无迁移。

## 完成定义

- [x] 自动与 UI 测试覆盖刷新链。
- [x] 设置持久化、详情和生命周期符合提案。

## 实施结果

- 旧实现核心测试 4/4 错误，证明缺少纯逻辑、相交查询和 UI 模块；主窗口接线测试 7 项中 4 失败、3 错误。
- 新增严格设置校验、半开区间跨日查询、置顶悬浮窗、geometry 防抖/可见屏恢复、只读详情和综合应用设置。
- MainWindow 唯一持有悬浮窗；手工/AI `data_changed` 统一刷新；日历/悬浮点击共用详情，多 ID 先选择；设置、托盘、主题、退出均完成接线。
- 独立终审发现“设置关闭但托盘临时显示后跨日不刷新”，新增失败用例后改为配置启用或实际可见时巡检刷新。
- 核心 13/13、主窗口集成 7/7、相邻回归 28/28；最终全量 89/89 通过。
- 早期一轮 Qt 测试存在只读隔离缺口，可能读取开发态 config/DB、没有写入；随后统一 mock 配置与查询，后续专项、全量与视觉测试均隔离。

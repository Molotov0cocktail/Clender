# Clender WebDAV 日程同步与静默自启动提案

## 目标

- 在 Windows 桌面版中提供仅日程数据的 WebDAV 双向同步，为后续多端客户端共享日程建立稳定数据契约。
- 在应用设置中提供 WebDAV URL、用户名、密码、连接测试、立即同步和启用开关。
- 提供当前 Windows 用户级开机自启动；自启动使用静默模式，不弹出主窗口。

## 非目标

- 不同步 AI 对话、API 配置、主题、字号、悬浮窗位置或其他本机设置。
- 不提供定时轮询或启动即同步；仅在本地日程成功变更后或用户手动请求后同步。
- 不支持 Digest、OAuth、客户端证书、端到端加密、共享日历权限或历史版本浏览。
- 不在开发态注册 Python 脚本自启动；开机自启动仅支持冻结后的 `Clender.exe`。

## 用户与运行环境

- Windows 当前用户、单实例 Clender 桌面应用。
- WebDAV 服务端需提供 HTTPS 目录和 HTTP Basic Authentication；常见场景使用专用应用密码。
- 用户接受密码明文保存在已被 Git 忽略并视为敏感数据的 `data/config.json`。
- 用户接受日程正文以未加密 JSON 存储在其 WebDAV 服务端；传输必须使用 HTTPS。

## 功能需求

1. 设置页包含 WebDAV 启用开关、目录 URL、用户名、密码、测试连接、立即同步与状态。
2. 目录 URL 下固定读写 `clender-events.json`；不存在时第一次同步创建。
3. 本地日程新增、修改、删除成功后触发后台同步；并发变更合并为后续一次同步。
4. 手动同步使用当前已保存设置；设置页“立即同步”先保存合法表单再请求同步。
5. 按跨设备 UUID 合并事件；冲突使用 UTC `updated_at` 最后写入者胜出；相同时间戳用规范 JSON 确定性决胜。
6. 删除以墓碑同步，防止另一设备的旧副本令事件复活；墓碑首版不自动清理。
7. 远端更新本地后刷新月/周/日、事件列表和今日悬浮窗，但不再次触发自动同步循环。
8. WebDAV 网络请求只在 `QThread` 中运行；UI 主线程只消费状态和刷新信号。
9. 开机自启动写入当前用户 `HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run`，命令为当前 exe 加 `--silent`。
10. `--silent` 启动不显示主窗口，保留托盘；若今日悬浮窗已启用则照常显示。托盘不可用时显示主窗口作为可恢复入口。

## 输入与输出

- 输入：HTTPS WebDAV 目录 URL、用户名、密码、启用状态、自启动状态。
- 远端输出：`clender-events.json`，格式为带版本号的 UTF-8 JSON。
- UI 输出：连接测试和同步的工作中、成功、无变更、失败短状态；错误不得包含密码或完整日程正文。

## 外部依赖与约束

- 复用锁定的 `requests==2.32.5`、PyQt5 和标准库 `winreg`，不新增依赖。
- WebDAV 使用 `PROPFIND` 测试目录，使用 `GET`/`PUT` 同步文件，使用 ETag 与条件写避免静默覆盖并发远端更新。
- 网络连接/读取超时必须有界；非 2xx、401/403、404 目录、412 冲突、畸形或过大 JSON 均作为受限错误处理。
- 数据库迁移必须幂等并兼容旧事件；所有测试使用临时 DB 和 mock HTTP。

## 成功标准

- 两个独立本地数据库可经同一远端文档合并新增、更新与删除，整数主键互不冲突。
- 本地变更和手动入口能触发同步；启动和空闲不会周期同步。
- 并发 ETag 冲突会重新拉取并有限重试，不会盲写覆盖。
- 设置保存、测试连接、同步失败和注册表失败均可恢复且不泄露凭据。
- `--silent`、普通启动、已有实例、无托盘回退行为有自动化覆盖。
- 全量测试、导入检查、Qt offscreen、完整 PyInstaller 与隔离 exe 冒烟通过，`dist/data/` 前后完整性一致。

## 验收检查

- 正常：远端缺文件、仅本地、仅远端、双方不同事件、同事件本地较新/远端较新。
- 边界：空日历、Unicode/长文本、相同时间戳、并发本地变更、412 一次恢复、墓碑。
- 异常：非 HTTPS、空账号字段、超时、连接错误、401/403/404 目录、500、畸形 JSON、未知 schema、过大文档、第二次 412。
- 回归：AI/手工 CRUD、事件查询、悬浮窗刷新、设置完整 JSON 保存、单实例激活、主题/字号、无显示器构造。

## 已确认假设

- 不做启动同步与五分钟轮询。
- 密码与现有 API Key 一样明文保存在忽略的配置文件中。
- 只支持 Basic Authentication。
- 自启动只支持冻结 exe；静默启动仍遵守悬浮窗启用状态。
